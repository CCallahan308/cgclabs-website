# UX and visual quality audit, October 25, 2026

## Design objective and scope

CGC Labs helps organizations evaluate an independent data engineer. The primary action is to email project sources, goals, and timeline. Service pages provide supporting detail.

Preserve the current identity, original logo, copy, claims, email address, prices, navigation, and clean routes. Refine the homepage routing diagram. Check the other five pages for regressions.

The user supplied a twenty-law UX review and a separate spacing gate. The user confirmed cgclabs.org as the target. The homepage contains the exact diagram examples in that request.

## Before implementation

The rendered production homepage was inspected at 1280 x 720, 768 x 1024, and 375 x 812. At 1280px, the Legacy systems label has approximately 2.7px of right clearance. Its left clearance is approximately 14.9px. This fails balanced internal padding. Output branches use different descriptor and title offsets around their endpoints.

### Proposed layout and spacing

- Keep the existing split hero. Use the vertical diagram below 1200px to preserve readable labels at smaller desktop widths.
- Use 24px board padding at 900px and above, and 16px below 900px.
- Use a 480 x 310 desktop SVG coordinate system.
- Give each source card 128 x 54 units with 16 units of left text inset.
- Use common source anchors at x=136 and pipeline anchors at x=208 and x=304.
- Put output endpoints at x=352, with radius 6, and text at x=376.
- Give both output groups identical descriptor and title offsets, relative to the endpoint.
- Give mobile two-line nodes 80-unit heights, 24-unit line spacing, and 40-unit connector gaps. Use 16-unit type.
- Keep text clear of connector branches. Measure text-to-connector and text-to-endpoint clearance independently.
- Retain CSS Grid and Flexbox for page layout. Use explicit SVG anchors only inside the diagram.
- Preserve the existing 44px minimum controls, visible focus, menu feedback, and reduced-motion rules.

## Implemented changes and verification

`index.html` now uses wider source cards, common output-label groups, documented SVG anchors, and a junction dot on the shared horizontal connector. Both diagram variants use the existing muted ink color for clearer connectors.

No JavaScript, marketing copy, metadata values, prices, routes, contact details, or dependencies changed.
