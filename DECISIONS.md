# DECISIONS: cgclabs-website (append-only)

1. **Static HTML instead of Next.js.** The two sibling sites are Next.js, but this build must be verifiable without npm/OneDrive node_modules, and the user deploys by dropping a folder. Theme Bible §8.3 explicitly blesses a static deploy path. If the site later needs a form backend or per-page components, port to Next.js using the same tokens.
2. **Theme Bible palette wins over Brand Kit.** Brand Kit uses Stone+Sage+teal (EB Garamond/Space Grotesk); Theme Bible uses Paper+Ledger Ink+Brick 70 (Source Serif 4/Inter/JetBrains Mono) and calls itself the single source of truth for cgclabs.org. Followed the Theme Bible.
3. **Three-lane site, analytics as flagship.** The 2026-09-02 rescope narrowed the offer to executive dashboards, but says "healthcare is the proof and the beachhead, not the fence." User directive 2026-09-27: three customer-facing pages, abilities-first, no client counts or live/pre-sale status language. Analytics page keeps the rescope offer and locked pricing; other two pages carry no prices and no outcome claims.
4. **No operator name or headshot.** Brand Kit guardrail ("the practice reads as a firm") plus the user's abilities-first instruction. First-person voice without naming; email only.
5. **mailto instead of Calendly.** No Calendly URL exists in the workspace. Used `christian.g.callahan@cgclabs.io` (from the Theme Bible contact spec). [to fill] swap in a Calendly link if one is set up.
6. **Pricing shown on analytics page only, verbatim locked numbers.** $8,500 30-Day Diagnostic (credited in full against month 1 of a retainer signed within 90 days); $15,000/mo retainer, no initiation fee, 1-month initial term then month-to-month (30-day notice). Lane B carries no published rate. Nothing anywhere else shows a price.
7. **"Fortune 250 quality" rendered as executive-grade.** The user's phrase is a quality-tier self-description; the brand voice requires specific, verified claims, so the copy conveys the standard through the verified proof points instead.

8. **Modern dark UI (2026-09-28).** User directive: the paper/serif Theme Bible aesthetic "looks bad," requested a modern UI with the hierarchy BI analytics first, websites second (eBay migration lives under websites), data engineering third. Replaced the light editorial system with a dark system (near-black surfaces, Space Grotesk display, Inter body, JetBrains Mono numerals, ember accent #FF7A50, subtle glow/grid hero, blurred sticky nav, rounded cards). Analytics is the featured full-width first card on home. Copy, guardrails, page structure, and the analytics-first ordering are unchanged; the Theme Bible visual spec is superseded by user instruction while its voice rules still apply.

9. **Reverted to the light Theme Bible design (2026-09-28).** User rejected the dark modern system as looking AI generated and off. Restored index.html, the three service pages, style.css, and site.js from commit d49f32a (the original paper/ledger-ink/brick build). The analytics-first ordering was already correct in that version. The dark experiment is closed; the Theme Bible light palette is the standing design.
