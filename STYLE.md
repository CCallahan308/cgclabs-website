# CGC Labs visual system

The source of truth is DESIGN.md, implemented in assets/style.css. The October 22, 2026 full rebuild supersedes earlier paper, serif, and Brick styling rules.

Use bright neutral surfaces, forest ink, and a restrained lime accent. Cabinet Grotesk provides display type; General Sans provides body and UI type through the official Fontshare API. Do not commit Fontshare binaries into this public repository.

Keep static HTML, short founder-led copy, clean routes, and verified evidence. Native SVG workflow diagrams describe services without implying live telemetry. No gradients, glass, stock imagery, fake dashboards, count-up evidence, or particle fields.

Keep the drawer CSS breakpoint aligned with site.js at 900px. The closed drawer uses inert and aria-hidden. Do not add a visibility transition that prevents immediate focus. Interactive targets are at least 44px. Preserve reduced-motion rules and visible keyboard focus on every surface.

Bump version queries when changing CSS or JavaScript. See TESTING.md for source and browser checks.
